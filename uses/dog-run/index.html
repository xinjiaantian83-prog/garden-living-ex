アメリカンフェンスで作るドッグラン

愛犬の飛び出しを防ぎながら、圧迫感を抑えた屋外スペースを作りたい方向けです。体格やジャンプ力、地面の状態を確認して高さと固定方法を選びます。

高さを選ぶときの考え方

低い仕切り

小型犬でも跳躍力には個体差があります。900mmを候補にする場合は、普段の行動と足掛かりになる物がないかを確認します。

高さを確保する囲い

活発な犬や高さが必要な場所では、1500×900パネルの縦張りを候補にします。高さだけでなく足元の隙間も確認します。

サイズ選びに迷う場合

犬種だけで決めず、体格、ジャンプ力、設置場所を伝えて相談してください。

サイズと価格を比較する

逃走防止で確認する場所

  • 足元掘り返しやすい地面とパネル下の隙間を確認します。
  • 門扉開閉方向と通路幅を決め、ヒンジとドアラッチを使って確実に閉じられるようにします。
  • 周囲室外機、台、植木鉢など、飛び越える足掛かりになる物をフェンスから離します。
  • 固定地盤や風当たりに合う基礎を選び、ポールのがたつきを防ぎます。

基本となる必要部材

  • 囲う部分900×900または1500×900のフェンスパネル
  • 支える部分張り方向と高さに合うポールH1500またはH2000
  • 接続部分パネルとポールを固定するジョイント
  • 出入口門扉にするパネル、ヒンジ、ドアラッチ

形状と寸法を入力すると、パネル・ポール・ジョイントの概算数量を自動見積で確認できます。
