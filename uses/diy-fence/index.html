施工前に確認すること

  • 設置位置境界、配管、扉の開閉範囲を確認し、各辺をmm単位で測ります。
  • 地面と風当たり土・コンクリートなどの条件に合う固定方法を選びます。
  • 安全強風地域、境界付近、地盤や埋設物が不明な場所は専門業者へ相談してください。

必要工具

  • 採寸・位置決めメジャー、水平器、墨出し・印付け用具
  • 固定・組立手袋、固定方法に合う穴あけ工具、レンチ等の締付工具
  • 基礎施工掘削用具、モルタルを扱う用具。現場条件により必要工具は変わります。

DIY施工の基本手順

  1. 1. 採寸・位置決めポール位置、扉の開閉範囲、各辺の通りを確認します。
  2. 2. 基礎とポールの固定水平・垂直を確認し、地盤と風当たりに合う基礎へ固定します。
  3. 3. パネルの連結手袋を着用し、寸法のばらつきをジョイントで調整しながら固定します。
  4. 4. 門扉の取付開閉方向を確認し、ヒンジとドアラッチを取り付けます。
  5. 5. 安全確認がたつき、足元の隙間、鋭利な箇所、門扉の開閉を確認します。
