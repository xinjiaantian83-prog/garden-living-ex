DIY施工の基本手順

  1. 1. 採寸・位置決め境界、配管、扉の開閉範囲を確認し、各辺をmm単位で測ります。
  2. 2. 必要部材の確認パネル、張り方向に合うポール、ジョイント、門扉部材、現場に合う基礎材料を揃えます。
  3. 3. ポールの固定通りと水平・垂直を確認し、地盤と風当たりに合う基礎へ固定します。
  4. 4. パネルの連結手袋を着用し、寸法のばらつきをジョイントで微調整しながら固定します。
  5. 5. 安全確認がたつき、足元の隙間、鋭利な箇所、門扉の開閉を確認します。

必要工具

  • 採寸・位置決めメジャー、水平器、墨出し・印付け用具
  • 固定・組立手袋、固定方法に合う穴あけ工具、レンチ等の締付工具
  • 基礎施工掘削用具、モルタルを扱う用具。現場条件により必要工具は変わります。
  • 判断に迷う場合強風地域、境界付近、地盤や埋設物が不明な場所は専門業者へ相談してください。
