Returns Policy

返品・交換について

ご注文前に返品・交換条件をご確認ください。商品に不良や破損などがあった場合は、状況を確認のうえ適切に対応いたします。

1. 返品・交換の基本方針

注文確定後のお客様都合による返品・交換は、原則としてお受けしておりません。商品名・型番・サイズ・数量・設置条件を十分にご確認のうえ、ご注文ください。

2. 対応可能なケース

以下の場合は、商品の返品・交換、再配送など必要な対応を行います。

  • 商品に初期不良があった場合
  • 配送中に商品が破損した場合
  • ご注文内容と異なる商品が届いた場合
  • 数量不足など、当店または配送側に起因する問題があった場合

3. 連絡期限

商品到着後に問題を確認された場合は、できるだけ早く、原則として商品到着後7日以内にご連絡ください。

開封時や到着時に破損・不良が分かる場合は、商品の状態、梱包、送り状などが分かる写真を添えていただくと確認がスムーズです。

4. 返品・交換できないケース

以下に該当する場合は、原則として返品・交換をお受けできません。

  • サイズ・数量の注文間違い、イメージ違い、不要になった、設置できなかったなど、お客様都合による場合
  • 屋外への施工後、取り付け後の商品
  • 切断・穴あけ・塗装など、加工後の商品
  • 使用により商品状態が変わった場合
  • 商品到着後7日を過ぎ、到着時の状態を確認できない場合

商品到着時に内容と状態を確認してから、施工・加工を行ってください。

5. 返送・再配送費用

初期不良、配送中の破損、誤配送など、当店または配送側の責任による返品・交換に必要な返送・再配送費用は、お客様のご負担にはなりません。

メーカー直送品のため、商品の状況確認や交換品の手配にお時間をいただく場合があります。配送事故の場合は、配送会社またはメーカーへの確認が必要になることがあります。

6. お問い合わせ方法

返品・交換に関するご連絡は、LINEまたはメールで承ります。ご注文内容と商品の状態が分かる情報をお知らせください。
