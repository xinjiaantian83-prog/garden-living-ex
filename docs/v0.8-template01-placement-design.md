# Version0.8 Template01 配置設計

## 目的

Template01「標準的な建売住宅の裏庭」をGarden Living展示場1号として扱い、5商品のA/B配置を確定する。

今回は本物の商品切り抜き素材、影、AI自然化、本番UI統合は行わない。半透明領域と簡易ラベルで、5商品を組み合わせた時に庭として成立するかを確認する。

## 画像解析

### 庭

画面下部から中央奥まで、土の庭が広く写っている。横幅と奥行きがあり、人工芝、タイルデッキ、フェンス、家具、ピザ窯の配置検証に向いている。

主要な庭エリア:

```json
[[0.02,0.56],[0.19,0.46],[0.53,0.46],[0.98,0.67],[0.98,0.98],[0.00,0.98]]
```

### 建物

右側に建物外壁が大きく写っている。建物は背景として強く、商品を置きすぎると圧迫感が出るため、右側配置の商品は控えめにする。

### 掃き出し窓

掃き出し窓は2か所。

| ID | 位置 | 役割 |
| --- | --- | --- |
| `center_window` | x:0.50 y:0.29 w:0.12 h:0.24 | タイルデッキBで接続対象 |
| `right_window` | x:0.76 y:0.13 w:0.17 h:0.42 | タイルデッキAの主接続対象 |

### 境界

左側境界と奥境界が見えるため、アメリカンフェンスの一辺配置・L字配置を自然に見せやすい。

| 境界 | 座標 |
| --- | --- |
| 左境界 | `[[0.00,0.67],[0.18,0.46]]` |
| 奥境界 | `[[0.18,0.46],[0.52,0.46]]` |

### 商品配置可能エリア

```json
[[0.09,0.58],[0.50,0.50],[0.93,0.69],[0.92,0.92],[0.06,0.93]]
```

商品を置く中心はこの範囲内とする。建物・窓・境界と干渉しないことを優先する。

## レイヤー仕様

Version1.0以降、Garden Livingは「施工順」に近いレイヤー構造で扱う。

背景レイヤーは「地面」のみとする。タイルデッキは背景へ含めず、商品レイヤーとして扱う。

### 背景レイヤー（地面）

| z_index | レイヤー | 対象 |
| ---: | --- | --- |
| 0 | 土（Before） | 初期状態 |
| 5 | 人工芝 | 芝庭After |
| 5 | 砂利 | 将来対応 |
| 5 | 真砂土 | 将来対応 |
| 5 | 土間コン | 将来対応 |

### 商品レイヤー

| z_index | 商品 | グループ | 理由 |

| 50 | ガビオン | 構造物 | 庭のアクセントウォール |
| 60 | ピザ窯 | 設備・家具 | 地面・デッキ上の設置物 |

| 60 | サウナ | 設備・家具 | 大型設備 |

## 商品別A/B配置

### 人工芝

#### A: ひろく敷く

```json
{
  "product": "turf",
  "pattern": "A",
  "type": "area",
  "polygon": [[0.06,0.56],[0.48,0.50],[0.95,0.68],[0.96,0.95],[0.03,0.95],[0.01,0.73]],
  "layer_kind": "background",
  "z_index": 5
}
```

庭の主要部分へ全面的に敷く。子ども・犬・家族時間の印象を最優先する。

#### B: 控えめに敷く

```json
{
  "product": "turf",
  "pattern": "B",
  "type": "area",
  "polygon": [[0.16,0.59],[0.53,0.53],[0.87,0.68],[0.83,0.88],[0.15,0.88],[0.08,0.73]],
  "layer_kind": "background",
  "z_index": 5
}
```

タイルデッキや家具との余白を残す。全部入り構成で使いやすい。

### タイルデッキ

#### A: 小さめ

```json
{
  "product": "tile_deck",
  "pattern": "A",
  "type": "area",
  "polygon": [[0.47,0.55],[0.96,0.67],[0.95,0.78],[0.42,0.69]],
  "layer_kind": "product",
  "z_index": 20
}
```

右掃き出し窓前へ標準サイズで配置。家具と相性が良い。

#### B: 広め

```json
{
  "product": "tile_deck",
  "pattern": "B",
  "type": "area",
  "polygon": [[0.33,0.52],[0.98,0.66],[0.98,0.85],[0.24,0.74]],
  "layer_kind": "product",
  "z_index": 20
}
```

中央窓と右窓の両方から使える広め配置。庭の主役になりやすい。

### アメリカンフェンス

#### A: 奥の一辺

```json
{
  "product": "american_fence",
  "pattern": "A",
  "type": "route",
  "route": [[0.17,0.48],[0.53,0.48]],
  "z_index": 50
}
```

奥境界に軽く抜け感を作る。圧迫感が少なく、初期提案に向く。

#### B: 左境界+奥のL字

```json
{
  "product": "american_fence",
  "pattern": "B",
  "type": "route",
  "route": [[0.03,0.68],[0.18,0.48],[0.54,0.48]],
  "z_index": 50
}
```

左境界から奥へL字に囲う。ドッグラン感と安心感を出す。

### ガーデンファニチャー

#### A: ダイニング

```json
{
  "product": "garden_furniture",
  "pattern": "A",
  "type": "object",
  "x": 0.68,
  "y": 0.70,
  "width": 0.18,
  "height": 0.12,
  "rotation": -4,
  "layer_kind": "product",
  "z_index": 70
}
```

右側タイルデッキ上へ配置。食事や会話のイメージを作る。

#### B: 休憩席

```json
{
  "product": "garden_furniture",
  "pattern": "B",
  "type": "object",
  "x": 0.42,
  "y": 0.70,
  "width": 0.20,
  "height": 0.11,
  "rotation": -2,
  "layer_kind": "product",
  "z_index": 70

```

中央寄りに置く低めの休憩席。芝庭との距離が近い。

### ピザ窯

#### A: デッキ脇

## おすすめ構成

### 1. まずは遊べる庭

- 人工芝A
- アメリカンフェンスA

目的:

土の庭が、子どもや犬が遊べる庭になることを最短で伝える。

### 2. 家族で過ごす庭

- 人工芝A
- タイルデッキA
- ガーデンファニチャーA

目的:

Garden Living展示場1号の基本構成。初期表示候補。

### 3. ドッグランの庭

- 人工芝A
- アメリカンフェンスB

目的:

犬あり家庭へ強い。用途が明確で相談につながりやすい。

### 4. 休日の食事を楽しむ庭

- タイルデッキA
- ガーデンファニチャーA
- ピザ窯B

目的:

ピザ窯を楽しみ要素として自然に見せる。

### 5. 全部入り控えめ

- 人工芝B
- タイルデッキA
- アメリカンフェンスA
- ガーデンファニチャーA
- ピザ窯B

目的:

Garden Livingの完成像を強く見せる。ただし初期表示ではなく比較用。

## 組み合わせ時の条件

- 背景レイヤーは地面のみ。土、人工芝、砂利、真砂土、土間コンを切り替える。
- タイルデッキは背景ではなく商品レイヤーとして扱う。
- タイルデッキと人工芝が重なる場合は、商品レイヤーであるタイルデッキを上位にする。
- ガーデンファニチャーはタイルデッキ上、または芝上でも不自然にならない範囲に置く。
- ピザ窯は掃き出し窓を塞がない。
- アメリカンフェンスは建物外壁に重ねない。
- 全部入り構成では商品を詰め込みすぎず、芝面の余白を残す。

## 評価

現時点では、Template01は展示場1号として成立する。

特に相性が良い構成は「家族で過ごす庭」。人工芝、タイルデッキ、ファニチャーの3点だけで体験価値が伝わる。

ピザ窯は魅力がある一方、先に見せすぎると用途が狭く見えるため、初期表示ではなくおすすめ構成の後半に置く。
