# Version 1.4 Template01 MVP Showroom

## Objective

Template01をGarden Living展示場1号として、ユーザーが商品を選択・解除すると完成イメージが即時に切り替わるMVPを作成する。

毎回AI生成は行わず、事前制作済みの固定画像をブラウザ内で切り替える。

## Adopted Rendering Method

MVPでは、商品ごとの完全透過レイヤー合成ではなく、見た目の自然さを優先した固定画像マッピング方式を採用した。

- 初期状態: Before（土の庭）
- 人工芝単体: 固定After画像
- ピザ窯単体: 土背景込みの固定画像
- 人工芝 + アメリカンフェンス: 背景込みの固定画像
- 人工芝 + タイルデッキ + 家具: 背景込みの固定画像
- ドッグラン寄り / ピザ窯寄りなど: 既存検証素材から近い構成を割り当て

## Why Not Pure Transparent Layers

以下の商品は単純透過合成だけでは営業品質に届きにくい。

- タイルデッキ: 遠近、目地、段差、掃き出し窓との接続が重要
- ガーデンファニチャー: 接地影とサイズ感が重要
- ピザ窯: 地面への接地、影、奥行きが重要
- アメリカンフェンス: 支柱間隔と奥行きが重要

そのため、MVPでは「自然に見える固定画像」を優先する。

## Current UI

- 初期状態は全商品未選択
- 商品ごとにON/OFFまたは最小限の選択肢を表示
- おすすめ構成プリセットを用意
  - 初期状態
  - 家族で使う庭
  - ドッグラン寄り
  - ピザ窯を置く
- 選択に応じて商品代合計（税込参考）を表示
- 選択内容を相談文へ反映
- LINE相談導線へ接続

## Price Handling

現時点ではMVP用の仮価格をフロント内で保持している。

将来的には価格DBへ接続し、以下の流れにする。

1. 商品選択
2. 価格DB参照
3. 標準価格と管理者上書き価格を比較
4. 表示価格を算出
5. 相談文へ反映

`display_price` は保存せず、必要時に算出する。

## Known Limitations

- すべての組み合わせに専用画像はまだ存在しない
- 一部の選択状態では代表イメージを表示する
- タイルデッキの色、サイズ、段数はUI上は選べるが、現時点では代表画像で表示する
- 完全なレイヤー合成エンジンではなく、固定画像切替MVPである
