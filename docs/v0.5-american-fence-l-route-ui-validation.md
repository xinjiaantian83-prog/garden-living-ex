## 成功条件判定

成功条件: 5回中3回以上で、2辺とも概ね指定ルートに沿い、折れ点で連続したL字配置になること。

結果: 5回中5回が成功条件を満たした。

L字ルート指定は、現時点の画像生成方式でも十分に有効と判断する。

## 直線方式との違い

| 指標 | 直線ルート | L字ルート |
| --- | ---: | ---: |
| 指定ルート追従 | 5 / 5 | 5 / 5 |
| 手前側への勝手な移動 | 0 / 5 | 0 / 5 |
| 片辺欠落 | 対象外 | 0 / 5 |
| 折れ点の連続性 | 対象外 | 5 / 5 |
| ゲート風の勝手な追加 | 2 / 5 | 2 / 5 |
| ズーム/トリミング | あり | あり |

直線方式と同様に、赤線入り指示画像は配置制御に強く効いている。L字でもAIは2辺の両方を認識し、折れ点で連続したフェンスとして扱えた。

一方で、ゲート風の分割と、1024px正方形出力によるズーム/トリミングは直線方式と同じく残った。これはL字固有の問題ではなく、現在の生成方式全体の制約と考えられる。

## 良かった点

- 5枚すべてで2辺が成立した
- 折れ点が自然に接続された
- 片方の辺だけになる失敗はなかった
- V0.4で強かった「手前に見せる広告配置」は出なかった
- 人工芝、植栽、舗装などの大きな余計な追加はなかった

## 残った問題

- 始点・終点はやや短縮される
- ゲートや開口部を勝手に作る傾向が残る
- 元写真が正方形へ寄るため、構図維持には限界がある
- ルート線を厳密な施工寸法として守るのではなく、視覚的な配置ガイドとして解釈している

## 結論

Version0.5 L字ルート検証は成功。

アメリカンフェンスは、ユーザーが写真上で指定した線を「配置指示画像」として渡す方式により、直線だけでなくL字でも十分に制御できる可能性が高い。

次へ進む場合は、いきなりコの字や面指定へ広げるより、以下を先に軽く検証すると無駄が少ない。

1. ゲート禁止をさらに強めた文言で勝手な開口が減るか
2. 端部短縮を抑える指示で始点・終点の保持率が上がるか
3. 正方形出力による構図変化を許容するか、別方式で回避するか
