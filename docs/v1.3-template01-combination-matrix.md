# Version1.3 Template01 組み合わせマトリクス

## 目的

Version1.2で確定した商品選択仕様をもとに、Template01で想定される選択状態、成立条件、事前制作が必要な固定画像数を整理する。

今回の目的は、画像制作数が増えすぎる箇所を把握し、MVPとして現実的な制作方式を決めること。

## 対象商品と状態数

| 商品 | 状態 | 状態数 |
| --- | --- | ---: |
| 人工芝 | なし / あり | 2 |
| タイルデッキ | なし + 色2 × サイズ2 × 段数2 | 9 |
| アメリカンフェンス | なし / 直線フェンス / ドッグラン向け囲い + ゲート | 3 |
| ガーデンファニチャー | なし / ダイニングテーブル + チェア | 2 |
| ピザ窯 | なし / レンガ造り・アーチ型・薪収納付き代表モデル | 2 |

## 理論上の総組み合わせ数

```text
人工芝 2
× タイルデッキ 9
× アメリカンフェンス 3
× ガーデンファニチャー 2
× ピザ窯 2
= 216通り
```

内訳:

| 区分 | 件数 |
| --- | ---: |
| Before状態を含む全状態 | 216 |
| Before状態を除く商品あり状態 | 215 |

Before状態:

```json
{
  "turf": "none",
  "tile_deck": "none",
  "american_fence": "none",
  "garden_furniture": "none",
  "pizza_oven": "none"
}
```

## タイルデッキによる増加分

タイルデッキは画像数増加の主因になる。

### タイルデッキ単体の状態数

```text
なし 1
+ 色2 × サイズ2 × 段数2
= 9状態
```

タイルデッキありのみ:

```text
色2 × サイズ2 × 段数2 = 8状態
```

| 色 | サイズ | 段数 | 内部例 |
| --- | --- | --- | --- |
| ナチュラルベージュ | 標準 | 1段 | `tile_A_step_1_color_natural_beige` |
| ナチュラルベージュ | 標準 | 2段 | `tile_A_step_2_color_natural_beige` |
| ナチュラルベージュ | 広め | 1段 | `tile_B_step_1_color_natural_beige` |
| ナチュラルベージュ | 広め | 2段 | `tile_B_step_2_color_natural_beige` |
| グレージュ | 標準 | 1段 | `tile_A_step_1_color_greige` |
| グレージュ | 標準 | 2段 | `tile_A_step_2_color_greige` |
| グレージュ | 広め | 1段 | `tile_B_step_1_color_greige` |
| グレージュ | 広め | 2段 | `tile_B_step_2_color_greige` |

### タイルデッキありの全組み合わせ数

```text
人工芝 2
× タイルデッキあり 8
× アメリカンフェンス 3
× ガーデンファニチャー 2
× ピザ窯 2
= 192通り
```

タイルデッキだけで、理論上の全体216通りのうち192通りに関与する。

## 成立しない組み合わせ

ここでの「成立しない」は、数学的に不可能という意味ではなく、MVPでお客様へそのまま見せる固定画像として営業品質にしにくい組み合わせを指す。

### 1. 家具あり + 人工芝なし + タイルデッキなし

理由:

- 土の庭へ家具だけを置くと、展示感が強くなる。
- 「庭で過ごす時間」よりも、仮置き感が出やすい。
- MVPでは人工芝またはタイルデッキのどちらかと組み合わせる方が自然。

件数:

```text
人工芝なし 1
× タイルデッキなし 1
× 家具あり 1
× フェンス 3
× ピザ窯 2
= 6通り
```

### 2. ドッグラン向け囲い + ゲート + 人工芝なし

理由:

- ドッグラン用途は、犬が走れる床面があることが前提。
- 土のまま囲うと、Garden Livingの「暮らしを楽しむ庭」として弱い。
- MVPでは人工芝ありを基本条件にする。

件数:

```text
人工芝なし 1
× タイルデッキ 9
× ドッグラン向け囲い 1
× 家具 2
× ピザ窯 2
= 36通り
```

### 重複分

上記2条件が同時に当てはまる状態:

```text
人工芝なし 1
× タイルデッキなし 1
× ドッグラン向け囲い 1
× 家具あり 1
× ピザ窯 2
= 2通り
```

### 除外対象合計

```text
6 + 36 - 2 = 40通り
```

## 実際に成立する組み合わせ数

| 区分 | 件数 |
| --- | ---: |
| 理論上の全状態 | 216 |
| MVP固定画像制作対象から外す状態 | 40 |
| 実際に成立する状態（Before含む） | 176 |
| 実際に成立する商品あり状態（Before除く） | 175 |

```text
人工芝なし 1
× タイルデッキあり 8
× ドッグラン向け囲い 1
× 家具 2
× ピザ窯 2
= 32通り
```

```text
タイルデッキあり理論数 192 - 除外32 = 160通り
```

| 区分 | 件数 |
| --- | ---: |
| タイルデッキあり理論数 | 192 |
| タイルデッキあり除外数 | 32 |
| タイルデッキあり成立数 | 160 |

## 事前制作が必要な固定画像数

制作方式によって必要枚数が大きく変わる。

### 方式A: 全組み合わせを完成画像としてプリレンダする

| 対象 | 必要枚数 |
| --- | ---: |
| 理論上の全状態 | 216 |
| Beforeを除く全商品状態 | 215 |
| 成立状態のみ | 176 |
| Beforeを除く成立状態のみ | 175 |

評価:

- 最も実装は単純。
- ただし制作枚数が多すぎる。
- タイルデッキ仕様変更だけで大量に作り直しになる。
- MVPでは非推奨。

### 方式B: 背景 + 商品レイヤー合成

推奨方式。

| レイヤー | 必要素材数 | 備考 |
| --- | ---: | --- |
| 背景 土 | 1 | Template01 Before |
| 背景 人工芝 | 1 | 確定済み人工芝After |
| タイルデッキ | 8 | 色2 × サイズ2 × 段数2 |
| アメリカンフェンス | 2 | 直線 / ドッグラン向け囲い + ゲート |
| ガーデンファニチャー | 2 | タイル上用 / 芝上用 |
| ピザ窯 | 3 | 土用 / 芝用 / タイル併用時 |

必要素材数:

```text
背景2 + 商品レイヤー15 = 17素材
```

評価:

- 176状態を17素材前後で表現できる。
- 価格や選択UIの変更に強い。
- 商品ごとに作り込み品質を上げられる。
- MVPの基本方式として採用候補。

### 方式C: タイルデッキだけ背景別に焼き込む

タイルデッキは地面との接地感が重要なため、土背景用と人工芝背景用を分けて制作する案。

| レイヤー | 必要素材数 | 備考 |
| --- | ---: | --- |
| 背景 土 | 1 | Template01 Before |
| 背景 人工芝 | 1 | 確定済み人工芝After |
| タイルデッキ | 16 | 背景2 × 色2 × サイズ2 × 段数2 |
| アメリカンフェンス | 2 | 直線 / ドッグラン向け囲い + ゲート |
| ガーデンファニチャー | 2 | タイル上用 / 芝上用 |
| ピザ窯 | 3 | 土用 / 芝用 / タイル併用時 |

必要素材数:

```text
背景2 + 商品レイヤー23 = 25素材
```

評価:

- 方式Bより制作数は増える。
- タイルデッキの接地感は安定する。
- タイルデッキの品質を最優先するなら現実的。
- MVPで違和感が出た場合の代替案。

## 画像数を減らせる互換・共用ルール

### 1. 人工芝は背景として共用する

- `soil_before` と `turf_after` の2背景で管理する。
- 人工芝は商品レイヤーではなく背景レイヤー。
- 他商品はこの背景上へ重ねる。

### 2. タイルデッキは8仕様を持つが、影・接地を共通化する

- 色差分はタイル面テクスチャのみ差し替える。
- サイズと段数は形状差分として管理する。
- 影はサイズごとに共通化できる可能性がある。

### 3. ガーデンファニチャーは販売商品ではなく演出レイヤー

- 商品DBを細分化しない。
- タイル上用と芝上用の2枚で十分。
- 色やメーカー選択は後回し。

### 4. ピザ窯は周辺地面とのなじみだけ分ける

- ピザ窯本体は1種類。
- 接地面だけ土、芝、タイル併用時で分ける。
- 本体画像を増やさない。

### 5. アメリカンフェンスのゲートは配置パターンに含める

- ゲートON/OFFを独立させない。
- `fence_A` は直線。
- `fence_B_gate` はドッグラン向け囲い + ゲート。
- これによりフェンス状態を3に抑える。

### 6. 不自然な組み合わせは制作しない

- 家具あり + 土のみ
- ドッグラン向け囲い + 人工芝なし
- これらは固定画像制作対象から外す。
- UIでは軽い案内またはおすすめ構成への誘導で対応する。

## 推奨結論

MVPでは方式Bを基本にする。

```text
背景2 + 商品レイヤー15 = 17素材
```

ただし、タイルデッキの接地感が営業品質に届かない場合のみ、方式Cへ切り替える。

```text
背景2 + 商品レイヤー23 = 25素材
```

全組み合わせの完成画像プリレンダは、175枚以上必要になるため現時点では採用しない。

## 次に確認すべきこと

1. タイルデッキを8仕様すべて作るか、最初はおすすめ4仕様に絞るか。
2. タイルデッキをレイヤー合成で成立させるか、背景別に焼き込むか。
3. 家具の芝上用とタイル上用の2素材を作るか、1素材で兼用するか。
4. ピザ窯の土用、芝用、タイル併用時の3素材が必要か、2素材で足りるか。
