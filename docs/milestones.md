# Milestones

Last updated: 2026-07-12

## Principle

Milestones are measured by user-touchable value.

Internal docs, specs, and roadmaps are project assets. They support milestones
but are not milestones by themselves.

## Milestone 0: Management Assets Ready

Goal:

Codex can continue meaningful work even if the human owner is absent for a week.

Project assets:

- A001 ブランドシーン設計
- A003 プロジェクト管理基盤
- Decision log
- Backlog
- Parallel work plan

User-facing deliverable:

- None

Done Criteria:

- Work can continue without constant human confirmation
- The next customer-value deliverable is clear
- Stop conditions are documented

Status:

In Progress

```text
自宅の庭写真で、庭の完成イメージを確認できる
```

Customer-value deliverables:

- D001 Garden Livingトップ価値訴求
- D002 Garden Living庭AI体験入口
- D003 Garden Living Before/After体験

Done Criteria:

- Page value is understandable before detailed text is read
- First visual or headline makes "自宅写真 -> 完成イメージ" obvious
- AI value appears before category browsing
- Before/After explains photo-to-completion intuitively
- Garden Living does not feel like a generic product catalog
- Carport/front-exterior messaging is not part of the Garden Living main flow
- Mobile first screen is understandable
