# Version0.7 Template01 世界観設計

## 位置づけ

Template01「標準的な建売住宅の裏庭」を、Garden Livingの展示場1号として扱う。

ここで目指すのは、単なる商品合成ではなく、ユーザーが「自分の家の裏庭もこう使えるかもしれない」と感じられる体験を作ること。

他テンプレートは一旦保留し、Template01の完成度を上げた時点でGarden Living全体の方向性を再評価する。

## 1. 想定ターゲット

### メインターゲット

- 30〜40代の夫婦
- 新築または築浅の建売住宅に住んでいる
- 子どもがいる、またはこれから家族時間を増やしたい
- 犬を飼っている、または飼いたい
- 庭はあるが、土のまま、砂利だけ、または活用できていない
- 外構に詳しくなく、何から考えればよいか分からない

### 心理状態

- 休日に庭を使いたいが、具体的な完成イメージがない
- 工事費が大きくなりそうで不安
- 営業される前に、自分たちでゆっくり比較したい
- 子どもや犬が安心して遊べる庭にしたい
- せっかく庭があるなら、食事やくつろぎにも使いたい

### 避けたい印象

- 高級すぎて自分たちには関係なさそう
- 商品を売り込まれている感じ
- 外構の専門知識がないと選べない感じ
- いきなり見積りや問い合わせを迫られる感じ

## 2. この庭で伝えたい体験

Template01で伝えるべき中心体験は、以下の4つ。

### 1. 子どもや犬が安心して遊べる庭

人工芝とアメリカンフェンスによって、土の庭が「遊べる庭」に変わることを見せる。

この体験は最も分かりやすく、Garden Livingの入口として強い。

### 2. 家族で外に出たくなる庭

タイルデッキとガーデンファニチャーで、リビングの延長として庭を使えることを見せる。

「庭に出る理由」を作る役割。

### 3. 休日に食事を楽しむ庭

ピザ窯を入れることで、庭が単なる空き地ではなく、家族や友人と過ごす場所になることを見せる。

ただしMVPでは主役にしすぎない。ピザ窯は最後に追加する楽しみ要素とする。

### 4. 何もない庭が、自分たちらしい場所になる体験

商品単体ではなく、組み合わせで暮らしが変わることを伝える。

「商品を選ぶ」よりも「庭で何をしたいか」を先に感じてもらう。

## 3. 商品優先順位と役割

### 1. 人工芝

**役割**

- 土の庭を一気に使える庭へ変える基礎商品
- 子ども、犬、裸足、遊び、見た目改善のすべてに効く
- Before/Afterの変化が最も分かりやすい

**Template01での扱い**

- 最初に見せるべき商品
- A/Bの違いは「広めに敷く」「中央を残して控えめに敷く」程度でよい
- Garden Livingの入口商品として扱う

### 2. タイルデッキ

**役割**

- リビングと庭をつなぐ
- 食事、椅子、テーブル、ピザ窯との相性が良い
- 人工芝だけでは出ない「外で過ごす場所」を作る

**Template01での扱い**

- 掃き出し窓前に自然につながる配置が重要
- 高さは低め、圧迫感を出さない
- A/Bの違いは「小さめ」「広め」で十分

### 3. アメリカンフェンス

**役割**

- 庭の範囲を作る
- ドッグラン感、安心感、抜け感を出す
- 境界を閉じすぎず、Garden Livingらしい軽さを作る

**Template01での扱い**

- 犬がいる家庭向けの訴求で強い
- ただし最初から囲いすぎると圧迫感が出る
- Aは手前または一辺、BはL字または囲い感のある配置にする

### 4. ガーデンファニチャー

**役割**

- 庭で過ごす人の気配を作る
- くつろぎ、食事、会話を想像しやすくする
- タイルデッキやピザ窯の価値を補強する

**Template01での扱い**

- 商品単体の訴求より、庭の使い方を伝えるために使う
- 小さめのテーブルと椅子で十分
- 大型家具は置かない

### 5. ピザ窯

**役割**

- Garden Livingらしさを強く出す象徴商品
- 休日、食事、友人、家族時間のイメージを作る
- ただし必需品ではなく、楽しみを広げる商品

**Template01での扱い**

- MVPでは最後に追加する
- 置き場所は端または奥側に限定
- 主役にしすぎると「ピザ窯サイト」に見えるため注意

## 4. MVP構成

### 推奨追加順

1. 人工芝
2. タイルデッキ
3. アメリカンフェンス
4. ガーデンファニチャー
5. ピザ窯

### 理由

**人工芝**

最も変化が分かりやすく、土の庭を「使える庭」へ変える入口。迷いなく最初に見せる。

**タイルデッキ**

人工芝だけでは遊び場止まりになるため、暮らしの場所としての庭を作る。リビングとの接続が分かりやすい。

**アメリカンフェンス**

子どもや犬の安心感を作る。ただしフェンスを先に出すと囲い込み感が強くなるため、人工芝とタイルの後がよい。

**ガーデンファニチャー**

庭で過ごす具体的な行動を補足する。商品としては後でも、体験理解には重要。

**ピザ窯**

最後に追加することで「楽しみのオプション」として自然に見える。最初に見せると用途が狭く感じられる。

### MVPで見せるおすすめ構成

#### 構成A: まずは遊べる庭

- 人工芝A
- アメリカンフェンスA

目的:

子どもや犬が遊べる最低限の庭を見せる。

#### 構成B: 家族で過ごす庭

- 人工芝A
- タイルデッキA
- ガーデンファニチャーA

目的:

Garden Livingの基本体験。最初のおすすめとして最もバランスが良い。

#### 構成C: ドッグランの庭

- 人工芝A
- アメリカンフェンスB

目的:

犬あり家庭向け。用途が明確で相談につながりやすい。

#### 構成D: 休日の食事を楽しむ庭

- タイルデッキA
- ガーデンファニチャーA
- ピザ窯B

目的:

ピザ窯を主役にしつつ、暮らしのシーンとして自然に見せる。

#### 構成E: 全部入り控えめ

- 人工芝B
- タイルデッキA
- アメリカンフェンスA
- ガーデンファニチャーA
- ピザ窯B

目的:

Garden Livingの完成イメージを強く見せる。ただし初期表示にはせず、選択肢として扱う。

## 5. UIイメージ

### 基本思想

スマホでは「編集する」ではなく「選ぶだけ」にする。

ユーザーに座標、拡大、回転、配置調整を求めない。Garden Livingがあらかじめ自然に見える配置を用意し、ユーザーは気分に近いパターンを選ぶ。

### 推奨画面構成

#### 1. 完成イメージ表示

画面上部に大きく完成イメージを表示する。

- スクロールしても商品選択より先に完成イメージが目に入る
- Before/After切替は後回しでよい
- 初期表示は「家族で過ごす庭」構成Bを推奨

#### 2. おすすめ構成ボタン

完成イメージ直下に、まず以下のプリセットを並べる。

- 遊べる庭
- 家族で過ごす庭
- ドッグラン
- ピザ窯の庭
- 全部入り

ここでユーザーは細かい商品選択をしなくても、すぐ完成イメージを切り替えられる。

#### 3. 商品ごとの切替

プリセットの下に、商品別の切替を置く。

各商品は横スクロールカードまたは縦並びカードで表示する。

表示例:

- 人工芝: なし / ひろく敷く / 控えめに敷く
- タイルデッキ: なし / 小さめ / 広め
- フェンス: なし / 一辺 / L字
- 家具: なし / 食事セット / 休憩セット
- ピザ窯: なし / 左奥 / 右奥

お客様向けには「パターンA/B」と表示しない。

#### 4. 選択中の商品一覧

商品切替の下に、現在選んでいる商品を短く表示する。

例:

- 人工芝
- タイルデッキ
- ガーデンファニチャー

ここでは価格の詳細を出しすぎず、「この内容で相談する」への橋渡しにする。

#### 5. 相談導線

画面下部に以下を表示する。

- この内容で相談する
- LINEで相談する

相談文には、選択中の商品構成とテンプレート名を入れる。

### スマホで迷わせないためのルール

- 最初に細かい商品一覧を出さない
- まずプリセットで体験させる
- 商品ごとの切替は5商品だけ
- 1商品あたり選択肢は最大3つ
- 「A/B」ではなく、お客様が意味を理解できる言葉にする
- 価格は初期画面では控えめにし、相談前に参考価格として見せる

## 6. Template01で避けるべきこと

- 最初からピザ窯を主役にしすぎる
- 商品を全部表示してカタログのように見せる
- お客様に配置を編集させる
- 商品名や仕様を先に見せすぎる
- 高級外構のように見せすぎる
- 価格を先に出しすぎて検討前に離脱させる

## 7. 成功条件

Template01の成功条件は以下。

1. 初見で「何もない庭が使える庭になる」と分かる
2. スマホで1分以内に3パターン以上を切り替えられる
3. 商品を知らなくても、庭での過ごし方が想像できる
4. 相談前に押し売り感がない
5. Garden Livingの展示場1号として、今後の方向性判断に使える

## 8. 次フェーズへの引き継ぎ

Version0.8で進める場合の候補:

4. 商品レイヤー素材の作成方針を決定
5. スマホ用の展示場UI試作へ進む
