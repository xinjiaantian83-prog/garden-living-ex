# Manual Review Checklist for Version 0.1

Use this when testing the Nesca F Wide vertical slice in the browser.

## Basic Access

- [ ] Page opens without console errors
- [ ] Existing Garden Living products load
- [ ] Existing category/search behavior still works
- [ ] AI simulator section is visible

## Carport Block

- [ ] "施工商品を選ぶ" block is easy to find
- [ ] "LIXIL ネスカF ワイド" is understandable
- [ ] Development note does not feel too confusing
- [ ] Enabling the checkbox reveals the option selectors

## Option Labels

- [ ] サイズ label is understandable
- [ ] 柱高さ displays customer language, not only internal code
- [ ] 本体色 is understandable
- [ ] 屋根材 is understandable
- [ ] 水下方向 is understandable for a non-professional user

## Price Display

- [ ] Price appears after enabling the carport
- [ ] Price label says "参考価格（税込・標準施工費込）"
- [ ] Temporary/development price status is clear enough
- [ ] Special construction note is visible but not scary
- [ ] Price does not feel like a final fixed quotation

## AI Generation

- [ ] Uploaded or sample photo still works
- [ ] AI generation button still works
- [ ] Generated image area still shows result/placeholder correctly
- [ ] Watermark remains visible
- [ ] Existing product item selection still works alongside carport block

## LINE Consultation

- [ ] Consultation text includes carport product name
- [ ] Consultation text includes size
- [ ] Consultation text includes height
- [ ] Consultation text includes body color
- [ ] Consultation text includes roof material
- [ ] Consultation text includes drainage direction
- [ ] Consultation text includes reference price
- [ ] Consultation text includes AI reference image notice
- [ ] Copy button works
- [ ] LINE button opens the expected LINE link

## Feeling Check

- [ ] Does this help the customer decide calmly?
- [ ] Does it feel like support, not sales pressure?
- [ ] Is there any wording that feels too technical?
- [ ] Is there any wording that overpromises?
- [ ] Is Version 0.1 clear enough to justify expanding to Version 0.2?
