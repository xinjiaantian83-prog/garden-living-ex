# Version0.6 固定テンプレ合成方式 技術試作

## 目的

Garden Living の次期シミュレーター方針として、AI画像生成ではなく「固定テンプレ構図 + 商品パターン切替」だけで、お客様が完成イメージを十分想像できるかを低コストで検証する。

今回の試作では、自由移動、自由拡大縮小、回転、遠近補正、自宅写真アップロード、AI自然化、AI画像生成は行わない。

## 採用した固定テンプレ庭画像

- `generated/v05-tile-deck-area/source.jpg`

選定理由:

- 住宅裏手・庭として使える構図で、Garden Living側の世界観に近い。
- 手前に庭スペース、奥に建物があり、人工芝・タイルデッキ・ピザ窯・家具・フェンスのレイヤー検証がしやすい。
- すでに生成/検証用資産として存在しており、本番ページを壊さず試作に使える。

注意:

- 本番採用時は、Garden Living用に権利整理済みのテンプレ庭写真を別途用意する。

## 技術結果

- API呼び出し: なし
- 画像生成APIコスト: 0円
- ブラウザ内Canvas合成: 即時
- 比較画像生成の平均描画時間: `generated/v06-template-composite/run-log.json` を参照
- スマホ操作: 商品ごとに「なし / A / B」をタップするだけ。ドラッグ操作なし。

## UX上の気づき

良い点:

- 操作が非常に軽く、ユーザーに編集スキルを求めない。
- 商品を動かすのではなく、自然な配置をGarden Living側で用意するため迷いが少ない。
- API待ち時間がなく、比較が速い。
- 「選ぶ → すぐ変わる」がスマホでも分かりやすい。

課題:

- 今回は簡易レイヤーであり、商品画像のリアリティ確認には不十分。
- 本番には透過PNG、影、接地感、色味調整済みの商品レイヤーが必要。
- 固定テンプレ構図と大きく異なる自宅写真にはそのまま適用できない。
- 商品数が増えると、全組み合わせを用意するのではなく「おすすめ構成」を編集部側で管理する必要がある。

## 次の推奨判断

採用方針:

- Garden Living のMVPは「固定テンプレ + 選択式合成」を主軸にする価値がある。
- 自宅写真アップロードは初期導線ではなく、テンプレ構図で体験価値を見せた後に別フェーズで扱う。

次にやるべきこと:

1. 5商品の実商品レイヤー素材を用意する。
2. 透過PNGまたは背景除去済みWebPを作る。
3. 影・接地・色味を1視点で事前調整する。
4. 今回の15通りから、お客様に見せる初期おすすめを3〜5通りへ絞る。
5. 本番ページへ統合する前に、スマホで「選択数」「理解速度」「迷い」を確認する。

今回まだやらないこと:

- 自由移動
- 自由回転
- 自由拡大縮小
- 自動遠近補正
- 自宅写真アップロード
- AI自然化
- AI画像生成
- 全242通り作成
- 本番ページ統合
