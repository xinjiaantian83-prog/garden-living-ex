# Garden Living / EXた組 Brand Scene Design

Last updated: 2026-07-12

## Core Principle

Garden Living と EXた組は、商品カテゴリではなく「住宅のどのシーンを作るか」で分ける。

判断基準:

- 住宅前面・住宅側面を作る商品や提案は EXた組
- 住宅裏手・庭を作る商品や提案は Garden Living

感情価値と機能価値では分けない。両ブランドとも感情価値と機能価値を持つ。

例:

- カーポートSCはEXた組の商品だが、照明や意匠による感情価値もある
- Garden Livingの商品も、施工性・耐久性・使いやすさなどの機能価値を持つ
- フェンスは外周境界ならEXた組、庭の目隠しならGarden Living
- ガビオンは門構えならEXた組、庭の演出ならGarden Living

# 1. Garden Living

## Concept

暮らしを楽しむ庭を作る。

Garden Livingは、住宅裏手や庭まわりで過ごす時間を豊かにするためのブランド。
商品を売ることよりも、ユーザーが自分の庭でどんな時間を過ごしたいかを想像し、納得して相談できる状態を作る。

中心価値:

- 庭で過ごす時間を想像できる
- 家族、犬、友人、自分のための空間を考えられる
- 商品単体ではなく、暮らしのシーンとして検討できる
- 購入前に完成イメージと参考価格を見られる

## Target

- 庭をもっと使いたい住宅所有者
- 子どもや犬と庭で過ごしたい人
- BBQ、ピザ窯、サウナ、アウトドアリビングに興味がある人
- いきなり営業相談する前に、自宅でゆっくり検討したい人
- 商品カタログだけでは完成後を想像しにくい人

## Worldview

キーワード:

- 庭時間
- くつろぎ
- 家族
- 犬
- 食事
- 外で過ごす
- 温かい生活感
- 上品だが気取らない

避けること:

- 施工業者感を前面に出しすぎる
- 商品一覧を最初から大量に見せる
- 価格訴求だけで押す
- 庭ではなく住宅前面・駐車場の印象を強くする

## Top Page Structure

推奨構成:

1. Hero
   - ブランドコピー
   - 「自宅の庭写真で、完成イメージを確認できます」を明確に伝える
   - 自宅写真 / サンプル庭で試す入口

2. Before / After
   - 施工前の庭写真
   - AI完成イメージ
   - 初見で「写真を入れるとこうなる」と理解できる構成

3. AI Garden Simulator Entrance
   - いきなり全UIを見せず、まず入口だけ見せる
   - 自宅写真で試す
   - サンプル庭で試す

4. Supported Garden Scenes
   - ドッグラン
   - BBQスペース
   - ピザ窯
   - タイルデッキ
   - 人工芝
   - 庭の目隠し

5. Product Categories
   - 商品カテゴリはAI体験後に配置
   - 探したい人向けの補助導線

6. Product List / Search
   - 初期状態では商品カードを大量に出しすぎない
   - カテゴリ選択後、検索後、すべての商品を見る操作後に表示

7. LINE Consultation
   - 「この内容で相談する」
   - 押し売りではなく、選んだ内容を共有する導線

## AI Simulator Structure

Garden Living版AIシミュレーターは「庭写真」を前提にする。

入口:

- 自宅の庭写真を使う
- サンプル庭を使う

主要ステップ:

1. 写真選択
2. シーン選択
3. 庭アイテム選択
4. 大まかな配置指定
5. 商品代参考または概算参考の表示
6. AI完成イメージ生成
7. 相談文生成
8. LINE相談

表示する価格:

- 商品代参考（税込）
- 設置費・施工費別途
- 現場状況により変動することを自然に伝える

## Target Products

- ピザ窯
- BBQスペース
- 人工芝
- タイルデッキ
- ウッドデッキ
- ガーデンファニチャー
- ドッグラン
- 庭用フェンス
- 目隠しフェンス
- サウナ
- ガーデンライト
- 立水栓
- ガーデンパン

## Target Scenes

- 庭
- 裏庭
- ウッドデッキ
- タイルデッキ
- ドッグラン
- BBQスペース
- アウトドアリビング
- 庭の水まわり
- 庭の目隠し

## Before / After Image Policy

Garden LivingのBefore / Afterは、生活シーンが伝わることを優先する。

Before:

- 実際の庭
- 使いきれていない裏庭
- 何を置くか想像しにくいスペース

After:

- 庭で過ごす時間が想像できる
- 商品を盛り込みすぎない
- 選択していない商品は追加しない
- 家族、犬、食事、くつろぎの雰囲気を自然に伝える

禁止:

- 住宅前面・駐車場の施工提案に見せる
- 商品を過剰に増やす
- AIが勝手に豪華な庭へ作り替える

## Conversion Flow

理想導線:

```text
トップで価値理解
-> Before / Afterを見る
-> 自宅写真またはサンプル庭で試す
-> 商品やシーンを選ぶ
-> 完成イメージと参考価格を見る
-> 納得した内容をLINEで相談
```

相談文には以下を含める:

- 選択シーン
- 使用写真
- 選択商品
- 配置
- 参考価格
- AI生成画像についての注意

# 2. EXた組

## Concept

住まいを作る外構。

EXた組は、住宅前面・住宅側面の外構を整えるためのブランド。
駐車場、玄関前、アプローチ、住宅側面など、住まいの使いやすさと見た目を作る。

中心価値:

- 住宅前面の使いやすさを改善する
- 駐車場や玄関まわりの完成イメージを事前に確認できる
- 施工前に価格感と仕様を整理できる
- 営業相談前にユーザーが自分のペースで検討できる

## Target

- カーポートや土間コンクリートを検討している人
- 玄関前、門柱、宅配ボックス、アプローチを整えたい人
- 住宅前面の外構をどうすればよいか分からない人
- 現地写真をもとに完成イメージを見たい人
- 施工相談前に価格感や仕様を比較したい人

## Worldview

キーワード:

- 住宅前面
- 駐車場
- 玄関前
- 使いやすさ
- 整う
- 施工提案
- 安心
- 現実的
- 住まいの顔

避けること:

- 庭時間やアウトドアリビングに寄せすぎる
- 裏庭・BBQ・ピザ窯の印象を混ぜる
- 施工可否を無視した派手な完成イメージ
- 選択していない商品を勝手に増やす

## Top Page Structure

EXた組のAIシミュレーター専用ページまたはトップ導線の推奨構成:

1. Hero
   - 「駐車場・玄関前の写真で、外構の完成イメージを確認できます」
   - カーポート、土間、門柱、宅配ボックスなどを明確に伝える

2. Before / After
   - 住宅前面・駐車場のBefore
   - AI完成イメージ
   - 「この場所に施工したらどう見えるか」を直感的に伝える

3. AI Simulator Entrance
   - 駐車場写真で試す
   - 玄関前写真で試す
   - サンプル住宅前面で試す

4. Supported Construction Scenes
   - カーポート
   - 土間コンクリート
   - 門柱
   - 宅配ボックス
   - アプローチ
   - 外周フェンス

5. Product / Plan Selection
   - 最初は少数の商品・仕様に絞る
   - 標準仕様中心
   - 特殊施工は別途見積りへ逃がす

6. LINE Consultation
   - 選択内容、価格、AI参考画像をLINE相談へつなげる

## AI Simulator Structure

EXた組版AIシミュレーターは「住宅前面・駐車場写真」を前提にする。

入口:

- 駐車場写真を使う
- 玄関前写真を使う
- サンプル住宅前面を使う

主要ステップ:

1. 写真選択
2. シーン選択
3. 商品選択
4. 仕様選択
5. 参考価格表示
6. AI完成イメージ生成
7. 相談文生成
8. LINE相談

仕様選択例:

- 台数
- サイズ
- 柱高さ
- 本体色
- 屋根材
- 水下方向
- 照明オプション

価格表示:

- 参考価格（税込・標準施工費込）
- 特殊施工・現場条件により別途

## Target Products

- カーポート
- 土間コンクリート
- 門柱
- 宅配ボックス
- アプローチ
- 外周フェンス
- ガビオン（門構え）
- 駐車場まわり
- 住宅側面まわり
- サイクルポート
- 物置

## Target Scenes

- 駐車場
- 玄関前
- アプローチ
- 住宅側面
- 外周境界
- 門構え
- 宅配導線

## Before / After Image Policy

EXた組のBefore / Afterは、施工後の現実感を優先する。

Before:

- 住宅前面
- 駐車場
- 玄関前
- 住宅側面
- 擁壁、道路、側溝、敷地境界が分かる写真

After:

- 施工後の使いやすさが伝わる
- 建物、窓、玄関、屋根、擁壁、道路、側溝を維持
- カーポートや門柱のサイズ感が現実的
- 選択していない商品は追加しない
- 特殊施工の正確な再現より、営業提案として完成イメージが伝わることを優先

禁止:

- 建物を勝手に変える
- 庭化する
- 人工芝や植栽を勝手に追加する
- 施工できない柱位置にする
- 駐車場範囲外へ柱を出す

理想導線:

```text
住宅前面の課題を認識
-> Before / Afterを見る
-> 自宅の駐車場・玄関前写真で試す
-> 商品と仕様を選ぶ
-> 参考価格を見る
-> AI完成イメージを見る
-> LINEで相談
```

相談文には以下を含める:

- 対象シーン
- 使用写真
- 商品名
- サイズ
- 仕様
- 参考価格
- 特殊施工別途の注意
- AI参考画像である注意

# 3. Common Strategy

## Cross-Linking

両ブランドは競合ではなく、住宅のシーン別導線として相互リンクする。

Garden LivingからEXた組へ:

- 「駐車場・玄関前の外構はこちら」
- 「カーポートや土間コンクリートを相談する」

EXた組からGarden Livingへ:

- 「庭・裏庭を楽しむ外構はこちら」
- 「ドッグランやBBQスペースを相談する」

リンクは押し売りではなく、ユーザーの目的地を案内する形にする。

## Brand Roles

Garden Living:

- 住宅裏手・庭
- 暮らしを楽しむ庭
- 庭写真から完成イメージ
- 商品代参考中心

EXた組:

- 住宅前面・住宅側面
- 住まいを作る外構
- 駐車場・玄関前写真から完成イメージ
- 標準施工費込み参考価格中心

## User Journey

ユーザーはブランド名よりも「自分が作りたい場所」で選ぶ。

入口の質問:

```text
どの場所を考えていますか？
```

選択肢:

- 駐車場・玄関前・住宅側面
- 庭・裏庭・ドッグラン・BBQスペース

この分類により、商品カテゴリで迷わせない。

## SEO Policy

SEOもブランド名ではなくシーン別に設計する。

Garden Living SEO:

- 庭 AI シミュレーション
- ドッグラン 庭 施工 イメージ
- 人工芝 庭 完成イメージ
- ピザ窯 庭 相談
- BBQスペース 庭
- タイルデッキ 庭

EXた組 SEO:

- カーポート AI シミュレーション
- 駐車場 外構 完成イメージ
- カーポート 施工 イメージ
- 土間コンクリート 相談
- 玄関前 外構
- 宅配ボックス 門柱 施工

SEOページは将来的に分ける:

- Scene pages
- Product pages
- Before / After case pages
- AI simulator landing pages

## Shared DB Policy

DB構造は共通化し、データの所属はブランド・シーンで分ける。

共通概念:

- product_id
- ai_spec_id
- price_matrix_id
- option_group_ids
- scene_scope
- brand_scope

推奨フィールド:

```json
{
  "brand_scope": ["garden_living"],
  "scene_scope": ["backyard", "dog_run"],
  "product_id": "...",
  "ai_spec_id": "...",
  "price_matrix_id": "..."
}
```

同じ商品でも、利用シーンが違えば表示先やAIプロンプトが変わる。

例:

- フェンス
  - `brand_scope: ex_takumi`, `scene_scope: boundary_fence`
  - `brand_scope: garden_living`, `scene_scope: garden_privacy`

- ガビオン
  - `brand_scope: ex_takumi`, `scene_scope: entrance_facade`
  - `brand_scope: garden_living`, `scene_scope: garden_accent`

## Shared Price Policy

価格構造は共通化するが、表示ラベルはブランド・商材種別で変える。

共通:

- standard_price
- override_price
- display price is calculated
- gross profit is calculated when needed
- final responsibility remains human

Garden Living:

```text
商品代参考（税込）
設置費・施工費別途
```

EXた組:

```text
参考価格（税込・標準施工費込）
特殊施工・現場条件により別途
```

## Shared AI Engine Policy

画像生成エンジンは共通化する。

共通関数:

```text
generateGardenImage()
```

または将来的に:

```text
generateExteriorImage()
```

エンジン共通、設定はブランド別。

共通入力:

- source image
- brand_scope
- scene_scope
- selected products
- selected options
- placement
- ai_spec_id
- prompt policy
- consultation context

ブランド別に変えるもの:

- prompt base policy
- sample images
- product options
- price labels
- consultation text
- Before / After examples

## Future Third-Party Sales

将来他社販売する場合は、Garden Living / EXた組の固有ブランドをそのまま売るのではなく、仕組みを汎用化する。

販売対象:

- AI外構シミュレーター
- 商品DB管理
- 価格DB管理
- LINE相談導線
- 施工会社向けAI提案ツール

汎用化のために必要な設計:

- tenant_id
- brand_config
- scene_config
- product_db
- ai_spec_db
- price_matrix
- option_master
- inquiry_template
- watermark config

他社導入時の考え方:

- 会社ごとにブランド設定を変える
- 商品DBは会社ごとに持てる
- AIエンジンは共通
- 価格や相談文は会社ごとに調整
- 生成画像には各社ウォーターマークを入れる
