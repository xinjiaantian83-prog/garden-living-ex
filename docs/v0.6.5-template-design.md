# Version0.6.5 Garden Living テンプレート設計

## 目的

Version0.6で採用した「固定テンプレ構図 + 商品パターン切替方式」を、Garden LivingのMVPとして使える形に整理する。

このフェーズでは画像素材の作成や本番実装は行わない。まず、どのようなビフォー写真をテンプレートとして持つべきか、各テンプレートにどの商品が合うか、どの組み合わせが売りやすいかを設計する。

## 基本方針

- テンプレ画像は外構工事前のビフォー写真のみを持つ。
- 完成後画像は持たず、商品レイヤーの組み合わせで作る。
- 最初は1テンプレ1視点を基本とする。
- お客様に自由配置を求めない。
- Garden Living側で自然に見える配置、角度、サイズを事前調整する。
- お客様は商品ごとに「なし / パターンA / パターンB」を選ぶ。
- 最初から全組み合わせを作らず、自然で売りやすい組み合わせを優先する。

## 対象商品

初期検証では以下5商品に限定する。

1. アメリカンフェンス
2. 人工芝
3. タイルデッキ
4. ピザ窯
5. ガーデンファニチャー

## テンプレート一覧

### Template01 標準的な建売住宅の裏庭

添付資料の「標準的な建売住宅の裏庭」を主な方向性とする。

**想定ターゲット**

- 新築または築浅の建売住宅に住むファミリー層
- 庭はあるが、まだ土のまま、または外構が最低限の状態
- 子ども、犬、家族時間、休日の庭活用に関心がある層

**撮影構図**

- 建物の掃き出し窓が1〜2か所見える
- 庭全体が手前から奥まで入る
- できれば左右どちらかの境界フェンスも見える
- 斜め構図を基本とし、奥行きが分かる写真にする
- 建物外壁、窓、庭の地面、隣地境界が同時に入ること

**使用できる商品**

- アメリカンフェンス: A/Bとも相性良い
- 人工芝: A/Bとも相性良い
- タイルデッキ: A/Bとも相性良い
- ピザ窯: B推奨。奥側または端に置きやすい
- ガーデンファニチャー: A/Bとも相性良い

**向いているシーン**

- 家族で過ごす庭
- 子どもが遊ぶ庭
- 犬と過ごす庭
- 休日に食事する庭
- 庭の基本リフォーム

**推奨する商品組み合わせ**

1. 人工芝A + タイルデッキA + ガーデンファニチャーA
2. 人工芝A + アメリカンフェンスB
3. タイルデッキA + ピザ窯B + ガーデンファニチャーA
4. 人工芝B + アメリカンフェンスB + ガーデンファニチャーB
5. 人工芝A + タイルデッキA + ピザ窯B + ガーデンファニチャーA

**備考**

最初に本番化するなら、このテンプレートが最も優先度が高い。Garden Livingの価値が伝わりやすく、5商品のすべてを自然に扱える。

### Template02 平屋・低層住宅の庭

**想定ターゲット**

- 平屋、低層住宅、郊外住宅に住むユーザー
- 庭との距離が近く、リビングから庭へ出やすい暮らしを求める層
- 落ち着いた庭時間、食事、読書、ペットとの時間を重視する層

**撮影構図**

- 建物の横長ラインが見える
- 掃き出し窓や縁側に近い位置から庭を撮影
- 建物の高さが低いため、空を入れすぎず庭面を広く見せる
- できれば軒や庇が少し入る構図

**使用できる商品**

- アメリカンフェンス: Bは控えめに使用
- 人工芝: A/Bとも相性良い
- タイルデッキ: A推奨。室内外のつながりを見せやすい
- ピザ窯: A推奨。端に小さく配置
- ガーデンファニチャー: A/Bとも相性良い

**向いているシーン**

- リビングの延長として使う庭
- 夕方にくつろぐ庭
- 夫婦や小家族の庭時間
- 低めの家具と落ち着いたアウトドアリビング

**推奨する商品組み合わせ**

1. タイルデッキA + ガーデンファニチャーA
2. 人工芝A + ガーデンファニチャーB
3. タイルデッキA + 人工芝B + ガーデンファニチャーA
4. ピザ窯A + タイルデッキA + ガーデンファニチャーA
5. アメリカンフェンスA + 人工芝A

**備考**

平屋は「広く見せる」よりも「暮らしの近さ」を見せる方が良い。商品を盛りすぎると生活感が薄れるため、2〜3商品構成が向いている。

### Template03 狭小庭

**想定ターゲット**

- 都市部や住宅密集地の小さな庭を持つユーザー
- 庭が狭く、何を置けるか分からず悩んでいる層
- 小さなスペースでも使える庭にしたい層

**撮影構図**

- 横幅より奥行きが分かる構図
- 建物外壁と境界フェンスが近くに見える
- 庭全体が一枚に収まること
- 手前に余白を作りすぎない
- できれば掃き出し窓を入れる

**使用できる商品**

- アメリカンフェンス: Aのみ推奨。Bは圧迫感が出やすい
- 人工芝: B推奨。範囲を絞る
- タイルデッキ: A推奨。小面積
- ピザ窯: 基本は非推奨。置くなら小さく端へ
- ガーデンファニチャー: B推奨。小型休憩席

**向いているシーン**

- 小さな庭の有効活用
- ミニドッグラン
- 洗濯物や外時間の小さなスペース
- 省スペースのアウトドアリビング

**推奨する商品組み合わせ**

1. 人工芝B + ガーデンファニチャーB
2. タイルデッキA + ガーデンファニチャーB
3. アメリカンフェンスA + 人工芝B
4. タイルデッキA + 人工芝B
5. 人工芝Bのみ

**備考**

狭小庭では「たくさん置ける」ではなく「この狭さでも使える」を伝える。ピザ窯は圧迫感が出るため、初期おすすめには入れない。

### Template04 犬走り・通路

**想定ターゲット**

- 建物横の犬走りや細長い通路を活用したいユーザー
- 雑草対策、ペット導線、目隠し、物置前の整備に関心がある層
- 庭というより、使いにくい外周スペースを整えたい層

**撮影構図**

- 建物外壁が片側に長く入る
- 反対側に境界フェンスやブロックが見える
- 奥行きが強く出る縦長または斜め構図
- 通路幅が分かるように足元を広めに撮る
- 奥まで見通せること

**使用できる商品**

- アメリカンフェンス: A/Bとも限定的に使用
- 人工芝: B推奨。細長い範囲
- タイルデッキ: 基本非推奨。舗装表現として小さく使う程度
- ピザ窯: 非推奨
- ガーデンファニチャー: 非推奨

**向いているシーン**

- 雑草対策
- 犬の通路
- 建物横の見た目改善
- 外周の整理
- 小さなフェンス・人工芝提案

**推奨する商品組み合わせ**

1. 人工芝Bのみ
2. アメリカンフェンスA + 人工芝B
3. アメリカンフェンスB + 人工芝B
4. タイルデッキA相当の舗装表現 + 人工芝B

**備考**

このテンプレはGarden Livingの「楽しい庭」というより、庭まわりの小さな困りごと解決に近い。ピザ窯や家具を入れると不自然になりやすい。

### Template05 庭が広い住宅

**想定ターゲット**

- 郊外住宅や広めの敷地を持つユーザー
- 庭を複数用途で使いたい層
- ドッグラン、BBQ、ピザ窯、遊び場、休憩スペースをまとめて検討したい層

**撮影構図**

- 庭全体を広めに入れる
- 建物は奥または片側に入り、庭面を主役にする
- 境界や外周が分かる
- できれば水平に近い構図
- 空や背景より、庭の面積が分かることを優先

**使用できる商品**

- アメリカンフェンス: B推奨。囲い感を出しやすい
- 人工芝: A推奨。大面積
- タイルデッキ: A/Bとも相性良い
- ピザ窯: A/Bとも相性良い
- ガーデンファニチャー: A/Bとも相性良い

**向いているシーン**

- ドッグラン
- BBQ・ピザ窯
- 家族や友人が集まる庭
- 複数ゾーンのある庭
- Garden Livingらしい主力提案

**推奨する商品組み合わせ**

1. アメリカンフェンスB + 人工芝A
2. 人工芝A + ピザ窯B + ガーデンファニチャーA
3. アメリカンフェンスB + 人工芝A + ピザ窯B
4. タイルデッキB + ガーデンファニチャーA
5. アメリカンフェンスB + 人工芝A + タイルデッキB + ピザ窯B + ガーデンファニチャーA

**備考**

広い庭は全部入り提案が成立しやすい。ただし最初の表示で盛りすぎると価格が重く見えるため、「基本」「ドッグラン」「アウトドアダイニング」の3系統に分けると選びやすい。

## テンプレ優先順位

1. Template01 標準的な建売住宅の裏庭
2. Template05 庭が広い住宅
3. Template03 狭小庭
4. Template02 平屋・低層住宅の庭
5. Template04 犬走り・通路

理由:

- Template01は対象ユーザーが広く、5商品すべてを扱いやすい。
- Template05はGarden Livingの魅力が最も出るが、実際の該当ユーザーはTemplate01より少ない。
- Template03は悩みが明確で、少ない商品でも価値が伝わる。
- Template02は世界観が出るが、写真素材の良し悪しに左右されやすい。
- Template04は実用寄りで重要だが、Garden Livingの主役体験としてはやや地味。

## テンプレ画像の撮影条件

各テンプレートで共通して満たしたい条件:

- 工事前の状態であること。
- 建物と庭の関係が分かること。
- 地面の範囲が広く見えること。
- 商品を配置する余白があること。
- 極端な広角歪みが少ないこと。
- 障害物、車、人、洗濯物などが主役になっていないこと。
- できれば曇天または柔らかい晴天で、強すぎる影が少ないこと。
- スマホ縦画面でも見やすいよう、主要配置範囲が中央にあること。

## MVPでの使い方

初期MVPでは、まずTemplate01だけを本番候補として深掘りする。

Template01で実施すること:

1. ビフォー写真を1枚選ぶ。
2. 5商品のA/Bレイヤーを作る。
3. おすすめ構成を3〜5通りに絞る。
4. ユーザーはテンプレ選択ではなく、最初から完成イメージ切替を体験する。
5. 手応えがあればTemplate05、Template03へ横展開する。
