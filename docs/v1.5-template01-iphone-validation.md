# V1.5 Template01 iPhone実機確認

## 目的

Template01 MVPをiPhone Safariで開き、Before画像から商品を選択し、完成イメージ・参考価格・相談内容・LINE相談まで迷わず進めるかを確認する。

今回は新しい固定画像制作ではなく、スマホでの操作性と状態整合性の確認を目的とする。

## ローカル起動手順

1. MacとiPhoneを同じWi-Fiへ接続する。
2. Macでプロジェクトへ移動する。

```bash
cd "/Users/yasudashinya/Documents/New project/garden-living-ex"
```

3. ローカルサーバーを起動する。

```bash
PORT=3012 npm run start
```

4. MacのWi-Fi IPを確認する。

```bash
ifconfig | grep "inet "
```

今回の環境では `192.168.3.33` が確認できた。変わる場合があるため、実機確認前に再確認する。

5. iPhone Safariで以下を開く。

```text
http://192.168.3.33:3012/
```

6. 終了するときは、Macのターミナルで `control + C` を押して停止する。

## iPhoneスクリーンショット取得手順

- Face ID搭載iPhone: サイドボタン + 音量上ボタンを同時押し。
- ホームボタン搭載iPhone: サイドボタン + ホームボタンを同時押し。
- 撮影後、写真アプリから確認する。

## 未制作組み合わせの扱い

未制作の組み合わせでは、別の不正確な完成画像を表示しない。

採用方針:

- Before画像を表示する
- 「この組み合わせの個別完成イメージは未制作」と明記する
- 選択内容・参考価格・相談文は反映する

理由:

- 近い代表画像を出すと、選択していない人工芝や家具が見える可能性がある
- お客様に「この組み合わせで完成画像がある」と誤解させない
- 相談導線は維持できる

## ユーザー判断が必要な項目

1. 未制作組み合わせをBefore表示で十分とするか、主要パターンから追加制作するか。
2. タイルデッキの色・サイズ・段数を、見た目にも反映する固定画像をどこまで作るか。
3. 商品代合計を「商品代参考」に留めるか、将来的に「施工費込み参考」へ拡張するか。
