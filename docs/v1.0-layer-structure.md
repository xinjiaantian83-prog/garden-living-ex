# Version1.0 Garden Living レイヤー構造

## 目的

Garden Livingのテンプレート合成を、施工順に近いレイヤー構造へ整理する。

商品を見せる順番ではなく、実際の庭づくりに近い順番で扱うことで、今後の商品追加時に破綻しにくくする。

## 基本方針

Garden Livingのレイヤーは以下の3段階で扱う。

1. 背景（地面）
2. 構造物
3. 設備・家具

## 背景レイヤー

背景レイヤーは「地面」のみ。

対象:

- 土（Before）
- 人工芝
- 砂利
- 真砂土
- 土間コン（将来）

背景レイヤーには、タイルデッキを含めない。

背景レイヤーは、庭のベース状態を切り替えるためのものとする。

## 商品レイヤー

商品レイヤーは、地面の上に施工・設置するもの。

対象:

- タイルデッキ
- アメリカンフェンス
- ガーデンファニチャー
- ピザ窯
- ガビオン
- 立水栓
- サウナ

## レンダリング順

| 順番 | グループ | 主な対象 |
| ---: | --- | --- |
| 1 | 背景（地面） | 土、人工芝、砂利、真砂土、土間コン |
| 2 | 構造物 | タイルデッキ、アメリカンフェンス、ガビオン |
| 3 | 設備・家具 | 立水栓、サウナ、ピザ窯、ガーデンファニチャー |

## Template01での扱い

Template01では、人工芝Afterは固定背景素材として扱う。

- Before: `images/templates/template01/template01-before.jpg`
- 人工芝背景: `images/templates/template01/template01-turf-after.jpg`

タイルデッキは人工芝背景へ焼き込まず、商品レイヤーとして後から重ねる。

## 今後の実装ルール

- `display_price` や `gross_profit` のような算出値は保存しない。
- 背景状態と商品状態を分ける。
- 商品追加時は、背景へ混ぜず商品レイヤーへ追加する。
- 地面工事と設置商品をUI上でも混同しない。
- お客様には「地面を選ぶ」「商品を選ぶ」の順に見せる。
